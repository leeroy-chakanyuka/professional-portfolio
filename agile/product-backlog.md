## 1. Purpose

The product backlog brings together proposed features, technical work and improvements. Priority and status should follow the actual team's Trello records rather than be reconstructed after the fact.

**Board:** [AquaLink on Trello](https://trello.com/b/5lxVBUSK/aqualink).

## 2. Documented backlog themes

The following categories appear in [Faith's AquaLink project summary](https://github.com/FaithA965/FaithA965.github.io/blob/main/agile.md#3-product-backlog):

| Category | Reported scope | What remains to verify |
|---|---|---|
| Research and requirements | Household needs, supplier information, water-access problem | Exact cards, owners and original priority |
| Project setup | Team roles, repository and development environment | Completion evidence and dates |
| Data model | Entities, attributes, relationships and ERD | Database artefact, owner and review outcome |
| Interface foundations | Colour system, shared components and responsive layout | UI task details and actual status |
| Technical review | Architecture, data model and changes | Review comments and approvals |
| Planned functionality | Household, supplier and admin areas; subscriptions and usage | Which features were actually implemented |

This is a **source-derived overview**, not a newly invented prioritised product backlog.

## 3. How individual backend contributions will be shown

For each relevant backlog item, record its exact Trello title and link, user value, agreed priority, assigned developer, implementation evidence, dependencies and final status.

Potential backend-related categories to investigate include the household/supplier schema, API contracts, water usage, payments and subscriptions. These are **areas to verify**, not statements that I completed those systems.

## 4. Change management

The teammates' published reflections indicate that AquaLink's business concept evolved during the early sprints. Once Trello is accessible, identify the actual cards or decisions documenting changes to scope, assumptions and priority.
